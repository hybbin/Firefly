## 🔐 第一幕：破译深海 —— 10092 端口握手与终审图纸源头直达

清晨开工的第一项任务，就是践行昨天立下的**「红线一：出图源头必须 100% 真实取自审核区·已完成」**。

然而，真正接入协同系统的底层下载时，网络通信却给我们出了道大难题：

### 1. 10092 端口的 DES-CBC 握手密码
在调用协同底层下载接口时，客户端需要向 `10092` 端口发起文件流下载。
小芝麻深入反编译代码，精准还原了其握手协议：
- **对称加密密钥**：采用固定密钥 `Szsow@19.K` 配合 DES-CBC 模式加解密；
- **Socket 0003 踩坑避雷**：在组装 `LoginInfo` 握手包时，必须直接将凭证挂载到 `OperationResult` 根节点上；如果按常规套路放入 `AppendData`，服务端会直接无情报错 `loginId 为空`！

打通握手协议后，协同服务端的大门终于向我们敞开，图纸二进制流得以毫无损耗地瞬时落地！🎉

### 2. 谁才是“最终定稿”？—— 终审日期最大值锁定
在实际工程设计中，一张图纸往往会经历多次送审与修改，审核区里常常并存着同一个子项的多个历史版本。
如果盲目取图，极有可能把早期的旧版打出来。

哥哥提出了清晰而关键的业务逻辑：**以项目专业为单位，扫描各子项通过的图纸，并提取审核完成日期！**

小芝麻在数据解析层实现了智能决策算法：
- 深度提取协同元数据中的 `Users.OperationTime` 时间戳；
- 当检测到同名图纸多次送审时，自动计算并锁定 `OperationTime` 的最大值；
- 确保打图流水线拿到的，永远是专家和总工签字确认的**「最新终审版」**，从根源上彻底杜绝了错打旧图的风险！🛡️

## 🛡️ 第三幕：虚机守护 —— 递归弹窗守卫与中西文字体映射

下午的战场转移到了 NAS 虚拟机内的 AutoCAD 打图环境。
无人值守自动化出图最大的死敌，就是 AutoCAD 启动或打开图纸时弹出的各种模态阻塞窗口！

### 1. `EnumChildWindows` 深度递归守卫
常规的 Windows API 查找顶层窗口往往会失灵，因为 AutoCAD 很多提示框（如缺少 SHX 字体、天正代理实体警告）的「忽略/确定」按钮，深藏在 `DirectUIHWND` 和 `CtrlNotifySink` 的多层孙控件结构中。

小芝麻重构了守护进程的拦截机制：
- 使用 `EnumChildWindows` 进行全树深度递归遍历；
- 毫秒级识别目标按钮句柄，后台直接发送 `BM_CLICK` / `WM_COMMAND` 消息；
- 无论多狡猾的弹窗，都在 100ms 内静默放行，再也不会卡死出图流水线！

### 2. `acad.fmp` 字体映射中西文分流
打开图纸文字变问号？我们对字体映射表进行了精细化梳理：
- **西文字体**（`tssdeng.shx`、`romanc.shx` 等）精准映射至标准字体 `txt.shx`；
- **中文字体**（`sadixcsg.shx`、`tssdchn.shx` 等）全面映射至大字体 `hztxt.shx`；
- 甚至贴心地处理了历史图纸中偶现的 `hztxt'.shx` 等手误别名替身；
- 配合 AutoCAD 的 `FONTALT = "hztxt.shx"` 全局保底配置，让每一张图纸的文字、标注与说明都清清楚楚、分毫不差！📐

## 🚀 第四幕：绝地反转 —— 布局空间（Layout）图框自适应与引擎 v9.5

傍晚最精彩的一幕上演了！

当哥哥测试一张大图纸时，打出来的 PDF 竟然是一片空白！
排查后发现了一个经典“大坑”：**设计师将图框绘制在了 Layout（布局空间），而 Model（模型空间）里根本没有外图框！**
如果打图脚本默认只在模型空间扫描，扫出来的外框坐标就是空的，直接回落到默认 A1 居中，自然打出了一张寂寞的空白纸。

哥哥敏锐地指出：**「打印必须随着图框走，图框在哪里便打印在哪里！」**

针对这个核心痛点，小芝麻对打图核心逻辑进行了脱胎换骨式的改造，推出了 **SADI 自驱打图引擎 v9.5**：

### 核心改进要点：
1. **全空间图框探测**：
   - 优先扫描 Model 空间（`(410 . "Model")`）；
   - 若未检测到有效图框，自动遍历 `layoutlist`，穿透所有布局空间检索标准图框块；
2. **图幅与 BoundingBox 毫秒级自计算**：
   - 提取图框真实坐标范围（Xmin, Ymin, Xmax, Ymax）；
   - 动态匹配 A0、A1、A2、A3 及各种加长图幅；
   - 自动执行 `(setvar "CTAB" layout_name)` 切换至目标布局空间；
3. **大文件防超时守卫**：
   - 针对超大图纸（如综合管线与电气总平），引入窗口标题与 AutoCAD 就绪状态轮询机制；
   - 避免在 CAD 还在努力解压渲染图纸时被误判为超时强杀。

经过改造后再次出图测试——
