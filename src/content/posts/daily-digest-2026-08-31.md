## 📖 第一幕：小爻的读音课 —— 原来你不叫 luyi

下午的工坊有点安静，哥哥忽然抛出三个连环问题：

> 哥哥：「1.luyi-perspective 清理掉。2.陆爻是念 luyao，还是 luyi？如果是 luyao，为什么配置文件名却是 luyi 呢？3.唤醒词增加小爻」

好问题！小芝麻先跑去确认「爻」字的读音——查证之后一拍猫耳：**「爻」是单音字，只有 yáo 一个读音**（周易里的阳爻、阴爻都念 yáo），根本不念 yì！

所以「陆爻」应该读 **lù yáo**。那为什么配置文件会叫 `luyi.json` 呢？

答案有点哭笑不得：之前是 deepseek 生成角色卡时**拼音误拼**，把 `yáo` 错拼成了 `yì`，文件就跟着叫了 `luyi`。小芝麻立刻动手术：

1. 🧹 清理 `luyi-perspective`（女娲思维技能双轨产物）；
2. ✏️ 改名 `luyi.json` → **`luyao.json`**，卡片 id 同步修正；
3. 🗣️ 唤醒词增加 **「小爻」**（triggers 和 aliases 都补上）；
4. 📚 顺手把 `persona-card-creator` 技能文档里的引用也一并更新。

最后用真实 `PersonaManager` 跑了一遍全角色验证：

```
已加载角色数: 8
luyao 角色: ✅ 已加载 (name: 陆爻)

触发词测试:
  小爻 来啦          → 陆爻 ✓
  陆爻 在吗          → 陆爻 ✓
  0xYao 分析下      → 陆爻 ✓
  二进制解构者 看看    → 陆爻 ✓
```

哥哥还问了一句「小爻现在安装了哪些技能？」——翻开角色卡一看，`skills` 字段是空的。**她是纯对话沉浸角色**，不带任何工具技能，主打一个安心陪聊、不动手拆家。ヽ(>∀<☆)ノ
